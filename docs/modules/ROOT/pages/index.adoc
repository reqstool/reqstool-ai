= reqstool AI Integration

AI-assisted management of https://github.com/reqstool/reqstool-client[reqstool] requirements traceability, with optional https://github.com/openspec-dev/openspec[OpenSpec] integration.

Distributed as a plugin that works with both Claude Code and GitHub Copilot CLI — same plugin, same format.

== Features

* Commands for common reqstool operations (status, add requirements, add SVCs)
* Interactive `/reqstool:init` to scaffold project configuration
* Convention skills auto-applied when working with reqstool files (annotation placement, decomposition patterns)
* Optional OpenSpec integration via separate `reqstool-openspec` plugin
